CaseNoter setup guide

CaseNoter 3.0.1 RC
Windows desktop

For staff invited to test the desktop preview. It opens as its own application with a CaseNoter window and taskbar icon.

Download CaseNoter 3.0.1 RC

The internal download requires access to the private CaseNoter repository. Release notes and checksums.

Only a confirmed Apricot save is a successful submission. Imported pending work stays available for review and is never automatically resubmitted.

Install and open

  1. Run CaseNoter-Setup.exe under your normal Windows account.
  2. Keep the default folder, C:\Casenoter. If your computer blocks that folder, choose a folder under your own Windows account. Setup does not need an administrator password.
  3. Select Housing or Education & Employment (EE&T). Both department builds are included, with separate credential vaults.
  4. Setup creates Start menu and desktop shortcuts and offers to open CaseNoter. If Microsoft WebView2 is missing, Setup installs it; an internet connection is required. If this fails, check the connection and retry Setup.

This internal preview is unsigned. Follow your organization's software approval process if Windows blocks it; contact support rather than changing computer security settings.

Connect your own Apricot account

  1. If starting fresh, choose Set up a new account, then choose a master passphrase. If you already use CaseNoter, follow Move your existing setup below instead. Keep your passphrase secure; it protects the credentials stored on this computer.
  2. Open Bonterra's credential page from the setup screen. Create credentials under your own staff account and paste the Client ID and Client Secret into CaseNoter.
  3. Let CaseNoter verify the connection and sync participant information. Newly created credentials can take time to activate. Follow the retry instructions; you can resume without typing the credentials again.

Change department

Close CaseNoter, run the same CaseNoter-Setup.exe again, and select Housing or Education & Employment (EE&T). Finish Setup and reopen CaseNoter. This changes which department opens while preserving both departments' existing credential vaults and settings. Unlock the selected department with its own master passphrase. If that department has no setup yet, connect your account or import its setup.

Move your existing setup

Keep your portable browser app and helper open. The desktop app can run alongside them. Save unfinished work before starting a transfer.

  1. Open the portable app in its usual browser profile and let it update to v2.6.9.6 or later. The portable update adds direct transfer support.
  2. In the desktop app choose Move my existing setup, also available in Settings. CaseNoter looks in Desktop, Downloads, nearby folders, immediate folders under C:\, and the current installation. Select your old installation or an encrypted setup export. Use Refresh or Choose folder if needed.
  3. For an installation folder, open the one-time transfer link in the browser profile you used for CaseNoter. Check the matching pairing code and running source folder, choose the department password to use, and approve the transfer. If the wrong profile opens, copy the link into a new tab in the correct profile.
  4. Return to the desktop app and enter your existing CaseNoter passphrase. Confirm replacement if this desktop already has a setup. CaseNoter verifies the account before restoring your saved setup.
  5. Wait for the completion message and restart. Both departments keep their original passphrases and saved encrypted data. Check both departments and keep the original installation until the new setup works. Imported pending work remains held in Pending requests for review.

Finding a folder does not identify its browser vault. If no vault is found, choose the correct browser profile and original address (normally http://127.0.0.1:8765; localhost is separate), or use the encrypted export fallback.

Encrypted export fallback

In portable v2.6.9.5 or later, unlock the original app and open Settings → Export my setup for upgrading to CaseNoter 3.0 → Export my setup. Select that file in the desktop import workflow and enter the existing passphrase. Both departments are included. A bare data folder cannot restore the browser vault.

Choose Set up a new account only when you want a new setup. Use transfer or export/import to add another computer for yourself. Never share your credentials or setup export with another staff member.

Daily use and closing

Open CaseNoter from Start, the desktop shortcut, or a pinned taskbar icon. Opening again brings the existing window forward. Apricot links open in your normal browser. Close the window or choose Quit to stop CaseNoter and its helper. Finish active saves first; pending or unconfirmed work is not saved.

Startup errors and diagnostics are available in the app. The portable helper can stay open. If another desktop session is using the desktop service port, close that desktop session and retry; contact support if the conflict persists.

Update, reinstall and uninstall

Interface updates continue from the installed folder. Internal prerelease builds skip automatic stable updates; Settings can check the stable channel. To upgrade the desktop shell, close CaseNoter and run the new CaseNoter-Setup.exe.

Credentials and settings stay in %LOCALAPPDATA%\CaseNoter, separate from the install folder. Reinstallation preserves them. Windows Installed apps can remove CaseNoter; keep local data when prompted unless you explicitly want to delete this computer's credentials and settings. Unsent work may be dropped. Apricot records remain unchanged.
