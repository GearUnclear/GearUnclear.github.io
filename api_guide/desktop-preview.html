CaseNoter setup guide

CaseNoter desktop
Internal preview

For staff invited to test the desktop preview. It opens as its own application with a CaseNoter window and taskbar icon.

Download CaseNoter-Setup.exe

The internal download requires access to the private CaseNoter repository. Release notes and checksums.

Only a confirmed Apricot save is a successful submission. Unsent notes, hours, assessments and drafts may be dropped during migration or removal. Check Apricot before re-entering anything with an unknown result, to avoid duplicates. Existing Apricot records are unaffected.

Install and open

  1. Run CaseNoter-Setup.exe under your normal Windows account.
  2. Keep the default folder, C:\Casenoter. If your computer blocks that folder, choose a folder under your own Windows account. Setup does not need an administrator password.
  3. Select Housing or Education & Employment (EE&T). Both department builds are included, with separate credential vaults.
  4. Setup creates Start menu and desktop shortcuts and offers to open CaseNoter. If Microsoft WebView2 is missing, Setup installs it; an internet connection is required. If this fails, check the connection and retry Setup.

This internal preview is unsigned. Follow your organization's software approval process if Windows blocks it; contact support rather than changing computer security settings.

Connect your own Apricot account

  1. Follow the instructions in CaseNoter to choose a master passphrase. Keep it secure; it protects the credentials stored on this computer.
  2. Open Bonterra's credential page from the setup screen. Create credentials under your own staff account and paste the Client ID and Client Secret into CaseNoter.
  3. Let CaseNoter verify the connection and sync participant information. Newly created credentials can take time to activate. Follow the retry instructions; you can resume without typing the credentials again.

Change department

Close CaseNoter, run the same CaseNoter-Setup.exe again, and select Housing or Education & Employment (EE&T). Finish Setup and reopen CaseNoter. This changes which department opens while preserving both departments' existing credential vaults and settings. Unlock the selected department with its own master passphrase. If that department has no setup yet, connect your account or import its setup.

Export my setup for upgrading to CaseNoter 3.0

The browser version's vault belongs to its exact browser profile and local address. Installing the desktop app does not automatically copy it.

  1. Keep the original installation and open it with the same browser profile and exact address you used before, normally http://127.0.0.1:8765. Let it update to public version v2.6.9.4 or later, then confirm the version in Settings. If automatic updating is unavailable, close the old helper and replace its HTML files with casenoter.html and casenoter-eet.html from the public update, then reopen the same browser profile and address.
  2. Unlock CaseNoter and open Settings → Export my setup for upgrading to CaseNoter 3.0. Select both departments if you use both, and unlock each selected vault when asked. Choose a separate transfer passphrase, then select Download encrypted setup.
  3. Keep the encrypted export file. It contains credentials and your selected ADP beta preference. Participant caches, client rosters, payroll grant configuration and unsent work are excluded. Payroll grant configuration has its own export in ADP settings.
  4. Close the old browser app and stop its helper. Open the desktop app and choose Import my setup. Select the file, enter its transfer passphrase and choose the destination passphrase. Confirm before replacing an existing destination setup.
  5. Wait for account verification and then sync the selected department. Check both departments if you transferred both. Keep the source setup until the destination works. An interrupted or failed transfer leaves the source credentials available for another attempt.

Use the same export/import process to add another computer for yourself. Never share your credentials or setup export with another staff member.

Daily use and closing

Open CaseNoter from Start, the desktop shortcut, or a pinned taskbar icon. Opening again brings the existing window forward. Apricot links open in your normal browser. Close the window or choose Quit to stop CaseNoter and its helper. Finish active saves first; pending or unconfirmed work is not saved.

Startup errors and diagnostics are available in the app. If another program is using port 8765, close the old portable helper and retry. Do not run the old helper and the desktop app together.

Update, reinstall and uninstall

Interface updates continue from the installed folder. Internal prerelease builds skip automatic stable updates; Settings can check the stable channel. To upgrade the desktop shell, close CaseNoter and run the new CaseNoter-Setup.exe.

Credentials and settings stay in %LOCALAPPDATA%\CaseNoter, separate from the install folder. Reinstallation preserves them. Windows Installed apps can remove CaseNoter; keep local data when prompted unless you explicitly want to delete this computer's credentials and settings. Unsent work may be dropped. Apricot records remain unchanged.
